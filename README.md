# In-Circuit ESR Meter
**Diseñado por: Ing. Pedro Luis López**

El **ESR Monster** es un medidor de resistencia serie equivalente (ESR) de alta precisión, diseñado para pruebas en circuito. A diferencia de los diseños convencionales, utiliza un **TL494** para generar una señal de 100kHz mucho más potente y estable.

## 🛠 Especificaciones Técnicas
* **Frecuencia de Operación:** 100kHz.
* **Rango de Medición:** 0.03Ω a 1.5Ω.
* **Voltaje de Salida:** 140mV (No activa semiconductores).
* **Consumo Máximo:** 95-100mA.

## 🔬 Funcionamiento del Circuito
* **Oscilador:** Basado en el integrado TL494, permite un ajuste fino del ciclo útil mediante RV1 (5kΩ).
* **Amplificación:** Dos etapas en cascada (Q1 y Q2) para manejar un miliamperímetro de 1mA/660Ω.
* **Rectificación:** Puente con diodos 1N4148 o 1N60 .
